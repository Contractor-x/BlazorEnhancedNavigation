# Blazor-Enhanced-Navigation

> A Blazor WebAssembly app built with enhanced navigation, layouts, and UI component structure.

---

## App Overview

**BlazorEnhancedNavigation** is a streamlined Blazor WebAssembly project showcasing advanced navigation, clean layout architecture, and reusable components. Ideal for developers exploring UI composition and routing in .NET's Blazor ecosystem.
